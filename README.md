# Estudo de Astro

Este repositório é um estudo prático do framework [Astro](https://astro.build/), desenvolvido
seguindo a [documentação oficial](https://docs.astro.build/). O projeto serve como espaço para
explorar os conceitos e as ferramentas do Astro enquanto construo um site pessoal com páginas,
componentes e publicações em Markdown.

## Tecnologias e conceitos explorados

- Páginas e roteamento baseado em arquivos com Astro.
- Componentes Astro e integração com Preact.
- Layouts reutilizáveis e estilos globais.
- Conteúdo em Markdown, listagem de publicações e páginas por assunto.
- Geração de um feed RSS.

## Como executar

Requer Node.js `>=22.12.0`.

```sh
npm install
npm run dev
```

O servidor de desenvolvimento estará disponível em `http://localhost:4321`.

## Outros comandos

| Comando | Ação |
| --- | --- |
| `npm run build` | Gera o site estático em `dist/`. |
| `npm run preview` | Pré-visualiza localmente a versão gerada. |
| `npm run astro -- --help` | Exibe as opções da CLI do Astro. |

Para aprender mais sobre o framework, consulte a [documentação oficial do Astro](https://docs.astro.build/).
