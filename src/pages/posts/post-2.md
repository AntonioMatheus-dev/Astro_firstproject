# Um site que também é um blog

Uma das coisas que mais gostei ao experimentar Astro foi perceber como um projeto pequeno pode reunir páginas, componentes e publicações sem complicar o caminho. Cada arquivo ajuda a transformar uma ideia em algo que dá para compartilhar.
